# Orinta Filatova — Product Portfolio

Static single-page site: `index.html` (inline CSS, no JS) and `assets/`. Open `index.html` directly to preview.

## Publish with GitHub Pages

1. Create a repository and push this folder's contents to the `main` branch (root).
2. In the repository, go to Settings → Pages.
3. Under "Build and deployment", choose Source: "Deploy from a branch", Branch: `main`, folder `/ (root)`, then Save.
4. After a minute the site is live at `https://<user>.github.io/<repo>/`.
